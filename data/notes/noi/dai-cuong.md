# Đại cương Nội khoa

Đây là ghi chú mẫu cho môn **Nội khoa**. Bạn có thể sửa trực tiếp file này (`data/notes/noi/dai-cuong.md`) hoặc thêm file `.md` mới trong cùng thư mục — mỗi file sẽ tự động xuất hiện trong danh sách ghi chú của môn.

## Cách thêm ghi chú mới
1. Tạo file `.md` mới trong `data/notes/noi/`.
2. Dòng đầu tiên nên là tiêu đề dạng `# Tên ghi chú` — tiêu đề này sẽ hiển thị trong danh sách bên trái.
3. Lưu file — không cần chạy lệnh import, ghi chú dùng trực tiếp từ file, chỉ cần khởi động lại `npm run dev` nếu app đang chạy.

## Ví dụ nội dung
- Hỗ trợ **in đậm**, *in nghiêng*, danh sách, bảng, v.v. (chuẩn Markdown).
- Có thể dán nguyên đoạn ghi chú ôn thi vào đây.
